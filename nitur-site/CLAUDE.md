# ניטור תצפיות — אתר

מערכת לניטור תצפיות על מש"קיות בתוכנית גשרים. המשתמשים הם מנה"דים, מפקדות ומנהלי מערכת, והם מזינים תצפיות וצופים בדוחות.
הבעלים: אלמוג (almogt@cyber.org.il). מנהלת שנייה: ShiriKle@cyber.org.il.

## ארכיטקטורה

- **Google Apps Script Web App**, באותו פרויקט Apps Script של גיליון Google בשם "ניטור תצפיות" (ID `1gXpKq_dm5KVliVUBL3Hfe2hOsENDb_aHWG6toYVYCYg`).
- **הגיליון הוא מקום האחסון בלבד.** אף משתמש לא פותח אותו. הנתונים חייבים להישאר ב-Google Workspace של הארגון, ולכן אין שרת חיצוני ואין בסיס נתונים חיצוני. זו דרישה שלא ניתן לשנות.
- הפריסה מוגדרת "הפעל בתור: אני" ו"גישה: כל מי שב-cyber.org.il". המשתמשים לא צריכים גישה לגיליון עצמו.
- קובץ שיוך חיצוני בשם "כא גשרים" (`1DjKCO0gbsplARuqtQE6L8dHw1rF_NklHdtKoG6BQBbc`) מסונכרן לגיליון "מיפוי".

## קבצים

| נתיב | מה זה | לאן מודבק בעורך Apps Script |
|---|---|---|
| `gas/SheetCode.gs` | קוד הגיליון (~10,000 שורות): CFG, `colMap_`/`findCol_`, טריגרים, גיליונות ניתוח, סנכרון | הקובץ הראשי הקיים |
| `gas/WebApp.gs` | השרת של האתר: זהות, הרשאות, API, מטמון, כתיבה | קובץ סקריפט בשם `WebApp` |
| `src/` | קוד המקור של הממשק: `shell.html`, `styles.css`, `js/*.js` | — |
| `dist/WebAppUI.html` | הממשק שנבנה מ-`src` בפקודה `npm run build` (קובץ יחיד) | קובץ HTML בשם `WebAppUI` |
| `test/` | חיקוי של Apps Script ב-Node, וגיליון מדומה במבנה האמיתי | — |

**לעולם אין לערוך את `dist/` ביד.** עורכים את `src/` ומריצים build.

## חוקים — לא לשבור

1. **הכל מאותר לפי שם כותרת, אף פעם לא לפי אות עמודה.** משתמשים ב-`colMap_`/`findCol_` ו-`W_FIELDS`. שורת הכותרות היא `CFG.HEADER_ROW` (4), והנתונים מתחילים ב-`CFG.FIRST_ROW` (5).
2. **אין לדרוס נוסחאות.** בעמודה "ציון תצפית" יש נוסחה בכל שורה, ומשורה 366 יש נוסחאות שליפה. כותבים רק תאים שהשתנו.
3. **טקסט חופשי עובר דרך `wText_`** לפני הכתיבה, כדי שערך כמו `=...` או `7/2` לא יהפוך לנוסחה או לתאריך.
4. **תאריכים נבנים דרך `wDate_(iso, tz)`** באזור הזמן של הגיליון.
5. **הזהות מגיעה רק מ-`Session.getActiveUser()`.** אין fallback לזהות של בעל הסקריפט. בעבר היה fallback כזה, והוא נתן הרשאות מנהל לכל מי שלא זוהה.
6. **כל סינון ההרשאות נעשה בשרת** (`wCanSee_`, `wCanEdit_`). הדפדפן מקבל רק מה שמותר לו לראות.
7. **ערך שמוחזר ל-`google.script.run` לא יכול להכיל `Date`.** מחזירים מחרוזות `yyyy-MM-dd`. הבדיקות אוכפות את זה.
8. **אין סקריפטלטים (`<?= ?>`) ב-HTML.** הדף מוגש סטטי ומבקש נתונים דרך `apiInit`, ו-build נכשל אם נמצא סקריפטלט.
9. **שמות גלובליים ב-`WebApp.gs` מתחילים ב-`w` או ב-`api`**, כי כל קבצי ה-.gs חולקים מרחב שמות אחד.
10. **הסקריפט לא מוחק גיליונות לעולם.** פעולה הרסנית מחייבת אישור מהמשתמש.
11. **אין לגעת בטריגרים בלי בקשה מפורשת.** קיים טריגר יומי ב-05:00 וטריגר עריכה, ושניהם של אלמוג בלבד.
12. **טקסט במסך תמיד כהה.** אין טקסט לבן, גם לא בכותרות.

## פקודות

```
npm install
npx playwright install chromium   # פעם אחת
npm run build          # src -> dist/WebAppUI.html
npm test               # build + בדיקות שרת (102) + קצה-לקצה בדפדפן (122)
npm run shots          # צילומי מסך של כל המסכים, במחשב ובנייד, לתיקייה shots/
```

**אחרי כל שינוי מריצים `npm test`, ואחרי שינוי ויזואלי גם `npm run shots`, ומסתכלים על הצילומים.**
כשמוסיפים יכולת, מוסיפים לה בדיקה: ב-`test/test-server.js` אם זה צד שרת, וב-`test/e2e-flows.js` אם זה זרימה בממשק.

## עיצוב

- עברית מלאה, RTL. גופנים: Frank Ruhl Libre לכותרות ו-IBM Plex Sans Hebrew לטקסט.
- כחול (`--blue`) לפעולה ולהזנה, אדום רק למה שדורש תשומת לב. ציון מתחת ל-`CFG.LOW_SCORE` (70) מסומן באדום.
- הטופס מעוצב כ"דף מחברת" עם קו שוליים ומספרי שלבים.
- תרשימים הם SVG בלי ספרייה, עם רמזים בריחוף ובמיקוד מקלדת.
- חובה לבדוק בנייד ברוחב 390px בלי גלילה אופקית.

## פריסה אצל אלמוג

1. מדביקים בעורך: את `gas/SheetCode.gs` לקובץ הראשי, את `gas/WebApp.gs` לקובץ `WebApp`, ואת `dist/WebAppUI.html` לקובץ `WebAppUI`.
2. **פריסה ← נהל פריסות ← עריכה ← גרסה חדשה ← פרוס.** בלי הצעד הזה הכתובת ממשיכה להגיש את הגרסה הישנה.

## פתוח / רעיונות

- לא נבדק מול הגיליון האמיתי, רק מול החיקוי. כדאי לבקש מאלמוג להזין תצפית ניסיון אחרי כל פריסה.
- נוסחת הגיליון סופרת קריטריון ריק כאפס. באתר תצפית חלקית מוצגת בלי ציון, אבל הנוסחה בגיליון עצמו לא תוקנה.
- אפשרויות להמשך: התראות במייל, הפקת דוח משוב ישירות מהאתר (היום הוא מופק דרך AutoCrat), השוואה בין סמסטרים.
