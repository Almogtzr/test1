# פורטל גשרים מדמ"ח

הקוד של הפורטל: `פורטל_גשרים_מדמח.gs` (Google Apps Script שמחובר לגיליון הניהול).

## איך מעדכנים את הקוד בגיליון
1. פותחים את גיליון הניהול > תוספים (Extensions) > Apps Script.
2. בעורך: Ctrl+A, מוחקים, ומדביקים את כל התוכן של הקובץ `.gs`. שומרים (Ctrl+S).
3. Deploy > Manage deployments > עיפרון (Edit) > Version: **New version** > Deploy.
   הקישור לפורטל לא משתנה.
4. חוזרים לגיליון ומרעננים את הדף (F5), כדי שהתפריט 🌉 פורטל יתעדכן.
5. (פעם אחת, אחרי עדכון שמוסיף הרשאה) בעורך בוחרים בפונקציה `authorize` ולוחצים Run, ומאשרים.

## מה יש בפורטל
- הודעות לפי דחיפות, "📌 חשוב עכשיו", "🆕 חדש ועודכן", קטגוריות, חיפוש, סינון לפי קהל.
- בכל כרטיס: ⭐ מועדפים (נשמר בדפדפן של כל משתמשת), 📋 העתקת קישור, 💬 שליחה בוואטסאפ.
- חיפוש סלחני: "משקיות" מוצא "מש"קיות", ומילים נמצאות בכל סדר.
- ⏰ תג"ב: ממלאים תאריך בעמודה M (לחיצה כפולה פותחת לוח שנה). עד התאריך המסמך מופיע בראש הפורטל
  ב"למילוי עד תאריך" עם ספירה לאחור, ו-3 ימים לפני הוא מסומן באדום. אחרי התאריך הוא חוזר למקומו הרגיל.
- ➕ הצעת מסמך: כל אחד מהצוות יכול להציע קישור. ההצעה נכנסת ללשונית "בקשות" ונשלח אליך מייל.
  בוחרים **אושר** בעמודת הסטטוס, והמסמך עובר ללשונית הקישורים ומתפרסם (והשיתוף שלו נפתח לכל מי שיש לו את הקישור, אם יש לך הרשאה לכך).
- מונה צפיות: סה"כ (עמודה I), ולפי קהל (K-L) לפי הקישור הייעודי שממנו נכנסו (`?role=m` / `?role=n`).

## תפריט 🌉 פורטל בגיליון
- פתיחת הפורטל
- 📨 בקשות ממתינות (עם מספר הממתינות)
- 📥 ייבוא קבצים מתיקייה בדרייב (נכנסים כטיוטות)
- 📊 דוח צפיות (כולל פילוח מש"קיות / מנה"דים)
- ✉️ טיוטת עדכון שבועי: נוסח מוכן להעתקה לכל קהל. לא נשלח כלום.
- התקנה מחדש: מוחקת הכל, ולכן מבקשת אישור.
