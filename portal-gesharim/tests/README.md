# בדיקות לפורטל

לא חובה להריץ. הבדיקות נועדו למי שמשנה את הקוד, כדי לוודא ששום דבר לא נשבר.

- `server.test.js`: בדיקות לצד השרת (גיליון מדומה ב-`mock.js`): סינון טיוטות וקישורים לא תקינים, זיכרון זמני,
  הדבקת כמה קישורים, מוני צפיות, הצעות, דיווחים, אישור בקשה, חישוב שגרות (כולל מעבר שעון), הגנה מנוסחאות.
- `build.js`: בונה דפי בדיקה מ-`sample-data.json` עם מקרי קצה (HTML זדוני, טקסט ארוך, אימוג'י), ודף עם 300+ מסמכים.
- `users.js`: 40 משתמשים מדומים במקביל, במכשירים, קהלים ומצבי תצוגה שונים, עם פעולות אקראיות.
  בודק שגיאות, גלילה הצידה, טקסט שבור, הזרקת HTML וגלילה שנשארת נעולה.
- `a11y.js`: בדיקת נגישות (axe, WCAG AA) בנייד ובמחשב, במצב בהיר ובמצב כהה.
- `perf.js`: זמני טעינה וחיפוש עם 300+ מסמכים, גם בטלפון איטי.

הרצה (מתוך התיקייה הזו): `npm install` ואז `npm test`.
