# עוזר דיווח עובדים-נט – גרסה 21

סקריפט Tampermonkey לאתר `net.rashi.org.il` (דיווח שעות ונסיעות).

## התקנה
Tampermonkey ← Create new script ← מדביקים את `rashi-net-helper.user.js` ← שומרים.
ההגדרות מגרסה 20 (קישור ושעות) עוברות אוטומטית.
ב-Chrome צריך להפעיל "Allow User Scripts" בפרטי התוסף (chrome://extensions).

## מה חדש מול 20.1
| תחום | שינוי |
|---|---|
| נסיעות | תצוגה מקדימה עם בחירה לכל שורה, זיהוי כפילויות (תאריך+סכום), דוח כשלונות, "בטל ייבוא אחרון" |
| נסיעות | קישור רגיל לגיליון עובד (בלי פרסום לאינטרנט), עמודות וסדר תאריך ניתנים להגדרה, תמיכה ב-`22,50` ו-ISO |
| שעות | מערכת שעות לכל יום בשבוע, ימי חופשה, לא ממלא ימים עתידיים, תצוגה מקדימה לפני מילוי |
| סיכום | ימים חסרים, נסיעה בלי שעות, יום מעל 12 שעות, קפיצה לתאריך, ייצוא לאקסל והעתקה |
| יציבות | פאנל רק במסגרת שיש בה טבלה, כל הסלקטורים באובייקט `SEL`, המתנה חכמה במקום sleep קבוע, נעילה נגד הרצה כפולה, `@connect` מוגבל לגוגל |
| UX | פאנל מתמזער ושומר מיקום, תג סטטוס חי, קיצורי Alt+Shift+H/T/S, בדיקת תקינות בהגדרות |

## בדיקה ראשונה על האתר האמיתי
1. הגדרות ← מתקדם ← 🩺 בדיקת תקינות – הכל צריך להיות ירוק.
2. ייבוא נסיעות – לבדוק שהתצוגה המקדימה מזהה נסיעות קיימות ככפילויות.
3. מילוי שעות בחודש עם ימים ריקים, ואז "סיכום ובדיקה".
